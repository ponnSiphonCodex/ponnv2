# วิธีรัน (สำคัญมาก — อ่านก่อน)

⚠️ **ห้ามวางหลายไฟล์/หลายคำสั่งรวมกันใน D1 Console เด็ดขาด**
สาเหตุบั๊คเดิม: วางรวมกันหลาย ALTER TABLE → พอมีคำสั่งไหนซ้ำ (duplicate column)
**ทั้ง batch ล้มทันที** — คำสั่งที่เหลือ (attendees, project_name, ตาราง team_roster ฯลฯ)
**ไม่ถูกสร้างเลย** ทั้งที่ Console โชว์ "Executed 6/6" (คือรันครบ 6 แต่ไม่ได้แปลว่าสำเร็จ 6)

## ทำตามนี้ทีละไฟล์ ห้ามข้าม ห้ามรวม
เปิดไฟล์ `01_...sql` → คัดลอกทั้งไฟล์ → วางใน D1 Console → กด Run → ดูผล → ไปไฟล์ถัดไป

- ไฟล์ที่ขึ้น "duplicate column name" หรือ "already exists" = มีอยู่แล้ว ✅ ข้ามได้ ไปไฟล์ถัดไป
- ไฟล์ที่รันสำเร็จ (ไม่มี error) = เพิ่งสร้างให้ ✅
- **ต้องรันให้ครบทุกไฟล์ 01-08** ถึงจะสมบูรณ์ (แม้บางไฟล์จะ error ก็ต้องไปไฟล์ถัดไปต่อ อย่าหยุด)

## ทำไมต้องแยกละเอียดขนาดนี้
เพราะ D1 (Cloudflare) รันสคริปต์หลายคำสั่งเป็น "ก้อนเดียว" — ถ้าใน 1 ก้อนมีคำสั่งพัง
คำสั่งอื่นในก้อนเดียวกัน **ไม่ได้รันจริง** แม้ Console จะแสดงผลลัพธ์ครบทุกบรรทัดก็ตาม
(เป็นจุดที่ทำให้เข้าใจผิดว่า "รันสำเร็จแล้ว" ทั้งที่จริงไม่สำเร็จ)

## ตรวจสอบว่าครบจริงหลังรัน
เปิด `09_verify.sql` รัน แล้วดูผลลัพธ์ — ต้องเห็นครบทุกคอลัมน์/ตารางตามที่ระบุ
